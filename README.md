# Montpellier Mobility Forecast

Personal project built on the open data API of Montpellier Méditerranée Métropole.

## Goals
1. Collect and store bike-share, car park and bike/pedestrian counter data.
2. Analyse bike and pedestrian usage (daily and weekly patterns, seasonality, weather).
3. Forecast short-term availability (car parks, bike stations) with machine learning.
4. Show current state and forecasts on an interactive map.

## Stack
Python, PostgreSQL/PostGIS, Docker Compose, scikit-learn / LightGBM, Streamlit.

## Data
Montpellier Méditerranée Métropole open data API (NGSI-LD), Apache 2.0.
https://portail-api.montpellier.fr
